# Full-Stack eCommerce Platform

A production-oriented full-stack eCommerce starter built from a real storefront codebase and generalized for reuse.

> Work in progress: the original storefront is being converted into a marketplace-ready, brand-neutral eCommerce product while preserving the proven architecture and UX patterns.

## Planned stack

- TypeScript + Vite storefront
- Node.js / Express API
- Firebase Authentication + Firestore
- Cart, checkout, orders, customer accounts
- Product catalog, variants, stock and reviews
- Transactional email flows
- Internationalization
- SEO-friendly product pages
- Admin tooling
- CI/CD and security checks

## Goal

Keep the architecture and interaction quality of the production storefront, remove all brand-specific and QR-specific behavior, and ship a clean, documented eCommerce platform that buyers can configure for their own store.
